{{ _('Why the rule is strict', 'لماذا القاعدة صارمة') }}

{{ _('A wrong suggestion can harm someone. So the decision “these two are the same” is made by a fixed rule that can be checked, not by a model that estimates. Units are converted first, so 0.5 g and 500 mg count as the same strength.', 'الاقتراح الخاطئ قد يؤذي المريض. لذلك قرار «هذان الدواءان متطابقان» تأخذه قاعدة ثابتة يمكن مراجعتها، وليس نموذجًا يخمّن. يتم توحيد الوحدات أولًا، فـ 0.5 جم و500 مجم يعتبران نفس التركيز.') }}
